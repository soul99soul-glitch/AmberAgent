# Advanced Execution Capability Gate Matrix

| Capability | Android expectation | iOS current state | Gate / risk | Main implementation decision |
| --- | --- | --- | --- | --- |
| Unified task state | Android maps SubAgent and Model Council runs into task snapshots with status, retry, output ref, cancel capability, and summary. | Chat run records exist; SubAgent/Council/Terminal each hold isolated transient status. | Persist only redacted summaries and safe logs; no secret payloads. | Add iOS-local advanced task records and store; runners write lifecycle states and retry metadata. |
| SubAgent | Roles define tool allowlist, budgets, task spec, status/result, transcript path. Tool scope is narrowed to discovery/read profiles. | `SubAgentRunner` calls KMP manager but uses fixed `ios-chat-dispatch` payload and returns a static status summary. UI has roles and overrides but no task input/history. | Tool scope must default read-only and never inherit dangerous tools without approval. | Add role descriptors, task payload builder, tool-scope summary, persisted run records, cancellation, retry, and chat-safe JSON/text outputs. |
| Model Council | Seats, rounds, output budget, per-seat turns, final result, partial failure, transcript and retry are first-class. | Council chat has live participant UI and custom seats; `CouncilRunner` only starts KMP manager and returns a static summary. | Real model calls may fail due API/network; failures must degrade honestly. | Persist council runs with selected seats/budget/process/conclusion; expose fallback conclusion when provider call fails or no API key. |
| Remote execution | Terminal/remote runtime exposes queued/running/completed/failed/cancelled/timed_out status, output tail, stop/wait/read. | SSH profile/test/smoke and `IOSTerminalRuntime` jobs exist; no persisted advanced task or chat tool exposure. | No real dangerous commands; remote actions require foreground approval and trusted host/password. | Add safe command request/status record path around existing runtime; UI shows last jobs, logs, retry/cancel/timeout. |
| Tool approval | Android resolver records action/source/reason and policy trace; high-risk tools ask/deny unless explicitly approved. | iOS `IOSPermissionStore` and foreground approval cards exist for memory/WebMount/MCP; status snapshot lacks decision records. | High-risk file/web/memory/remote actions require fresh user action; no global auto approval. | Add approval records and remote/subagent/council capabilities to iOS permission status; keep default ask/deny policy. |
| Chat result refill | Android tool results return structured outputs to the model after approvals. | `ChatViewModel` refills tool calls for memory/WebMount/MCP/SubAgent/Council. | Tool output must be honest, bounded, and not fake success. | Return structured advanced-task summaries from SubAgent/Council and keep streaming resume path unchanged. |
| UX closure | Advanced features should be real settings, not static docs or experimental pages. | SubAgent role page says custom tool/budget later; execution page only links remote; Council settings lacks run budget visibility. | No visual redesign or experimental hiding. | Add compact controls/status/history using existing Amber form rows and sections. |
