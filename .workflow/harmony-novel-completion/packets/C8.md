# Packet C8 — 产品终验与旧链清退

## Objective

清退已经被 Chat-backed canonical runtime 与 durable job 取代的旧 Novel 链，补齐 Harmony 自身历史
存储迁移、交互 run 离页重连和空项目 Quick Start，完成两域回归、签名构建、指定真机安装与 UI 复核。

## Invariants

- Novel 模型事件只允许 canonical immutable snapshot；不保留 `delta/replace/activity` 兼容事件。
- 页面离开只解除 UI 订阅，不停止 provider；重新进入同一项目必须取回相同 run 与最近 snapshot。
- active snapshot 以 run 启动时的 historyCount 切尾，checkpoint 后重开页面不得重复消息。
- 讨论缺信息使用原生 `ask_user`；工作区改动使用 `novel_workspace_write` 审批，不再产生 fenced JSON。
- `filesDir/novel_deleted/*.novel.json` 是真实升级输入；成功安装 workspace 后才删除，损坏证据保留。
- durable ghostwrite/polish、canonical transcript、分支和版本 reader 不得随旧 batch 清理误删。
- 用户脏 `NovelBatchPolishSheet.ets` 已无 caller，但本 Phase 不覆盖、不删除、不暂存。

- DeepRead/Chat 全域单测、双域 TypeScript、ArkTS lint、AGC 签名构建、指定真机覆盖安装。
