# Packet C3 — 工作区 v1、交换与书籍导出

## Objective

把小说项目从单 JSON 持久化迁入 `amber.novel.workspace` v1 文件工作区，建立可见树与私有
`.amber` 边界，并让项目 CRUD、ZIP 往返及当前分支 TXT/Markdown/EPUB 导出真实可用。

## Ownership

- 主 agent：工作区 repository、Entry 文件端口、DI/UI 集成、真机交换闭环和最终修复。
- `c3_workspace_exchange`：ZIP 交换格式、限额、路径/冲突校验和单测。
- `c3_book_export`：TXT/Markdown/EPUB 纯域生成及单测。
- `c3_logic_review`：只读检查数据正史、迁移、恢复、交换边界与 CRUD 竞态。
- `c3_ui_review`：只读检查项目页、导出菜单、系统 picker、反馈态与触控区。

## Invariants

- 生产链唯一为 UI → `NovelWorkspaceService` → 单例 workspace repository → `FileStore`。
- 旧 JSON 仅作一次性迁移输入；工作区安装成功后才删除旧文件。
- 公开 ZIP 必须包含 `manifest.yaml` 与 `project.md`，不得包含 `.amber/`。
- `project.md` 是用户可维护公开文件，导入及业务状态更新不得改写其字节。
- ZIP 解包前拒绝绝对/逃逸/隐藏路径、重复项、文件目录冲突和超限元数据。
- 写入使用 staging/live/backup 目录切换；同项目 update/delete 共用串行锁。
- EPUB 复用 Chat ZIP writer，首项 `mimetype` 必须 stored，其余可 deflate。
