# Packet C2 — 共享交互运行时与真实流式

## Objective

让 Novel 复用 Chat 的 provider、SSE parser、`MessageStreamAccumulator`、retry、
transformer 与 abort，页面只消费 canonical `UIMessage[]` 快照；同时用真实 NetStack
`dataEnd` 区分 `live / buffered / unavailable`，不把 Markdown 动画当网络流式。

## Ownership

- 主 agent：Chat façade、Novel adapter、transport telemetry、页面接入、测试和真机闭环。
- `c1_logic_review`：只读检查 transport、retry、模型解析、工具 step、regenerate 和续跑链。
- `c1_ui_review`：只读检查活动消息、Markdown、键盘缩屏、裁剪、gutter 和触控区。

## Invariants

- provider/解析器/accumulator 只有 Chat 生产链一份；Novel 不解析 SSE。
- `generationActive` 与 `textDeltasLive` 分离；首帧不足以证明 live。
- transport 以实际 `dataEnd` 和 parsed delta 时间判定；整包不得先闪成 live。
- 每次 provider 请求以真实 accumulator seed 作 baseline，retry/tool/regenerate 不得沿用旧请求。
- 显式 Novel model 精确解析并 fail closed，不得静默回退默认 Chat model。
- retry reset 必须把失败 partial 从 Novel UI/持久化候选清掉；等待可被 abort 立即结束。
