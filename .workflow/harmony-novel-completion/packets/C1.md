# Packet C1 — 共享消息呈现深模块

## Objective

让 Chat 与 Novel 共用 canonical 富消息协议、`AgentMessageRow` 和
`InteractiveMessageTimeline`，同时保留 Novel 的领域 footer/提案卡，不复制 Markdown、
reasoning、tool、ask-user 或滚动呈现轮子。

## Ownership

- 主 agent：协议迁移、组件提取、Chat/Novel 接入、测试、真机诊断与集成提交。
- `c1_logic_review`：只读协议/调用链/capability/Builder 复核。
- `c1_ui_review`：只读截图、gutter、边距、字号、长 Markdown 与输入区复核。

## Invariants

- canonical `UIMessage` 只在 DeepRead 定义；Chat 仅重导出。
- Timeline 是消息区横向 gutter 的唯一 owner。
- host capability 只控制操作，不得隐藏 tool/ask/subagent/council/mini-app 内容。
- 不支持的操作不得注册 no-op 点击或长按手势。
- 传给子组件且读取父状态的局部 `@Builder` 必须用箭头包装，保持父组件 `this`。
