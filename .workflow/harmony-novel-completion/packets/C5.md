# Packet C5 — 小说工作台、持久对话与职责模型

## Objective

让 Novel 不再保存纯文本假对话或复制简化渲染链：完整复用 Chat 的 canonical transcript、交互运行时、
tool loop、reasoning、停止、Markdown 与消息呈现，并把职责模型、三视图和 C4 durable proposal 接成
可重进、可恢复、可审计的产品链。

## Ownership

- 主 agent：canonical transcript 与 C4/C5 集成、NovelCreation 恢复边界、Entry 装配、工作台 UI、真机验收。
- `c5_transcript_chat_audit` / `c5_tool_ask_audit` / `c5_model_policy_audit` / `c5_workspace_ui_audit`：
  只读差距与复用边界审计。
- `c5_transcript_domain` / `c5_novel_tool_catalog` / `c5_interactive_tool_runtime`：
  transcript、工具目录与 Chat runtime 的窄切片实现/复核。
- `c4_logic_gate` / `c4_ui_gate`：C5 最终调用链与真机 UI gate，修复后再次复核。

## Invariants

- canonical `UIMessage.parts` 是唯一新写 transcript；legacy content 只迁移读取。
- Novel 复用 Chat runtime/tool loop/renderer，不复制 SSE、Markdown、follow、reasoning 或 ask-user 轮子。
- tool verdict 先 durable checkpoint，再执行受保护 write；toolCallId 不变，commandId/receipt 确定且幂等。
- proposal 不存在、pending、rejected、accepted 四态在重进时有确定语义；相反终态 fail closed。
- fixed model 必须精确 providerId + ProviderModel.id 且鉴权可用；不得回落 legacy registry 或全局模型。
- 三视图只读写真实 branch/workspace state；反馈位于动作附近，点击区至少 44vp。
