# Packet C4 — 分支正史、受控写入与一致性

## Objective

在 C3 单一文件工作区上开放真实 mutation：以 append-only ledger、branch head/tree CAS、
durable receipt 和分支快照构成正史，并让分支、受控 proposal、一层 undo、unresolved 与
plot freshness 从仓储到产品入口闭环。

## Ownership

- 主 agent：历史纯域、workspace repository、`NovelCreation` 生产接线、ArkUI 分支入口、真机验收与修复。
- `c4_android_reference` / `c4_harmony_gap` / `c4_ui_entrypoints`：只读核对 Android 固定基线、鸿蒙缺口和真实页面入口。
- `c4_history_domain2` / `c4_repository_store` / `c4_branch_sheet`：边界明确的纯域、仓储与 UI 实现切片。
- `c4_logic_gate` / `c4_ui_gate`：最终逻辑调用链与真机 UI 审查，修复后再次复核。

## Invariants

- 每个受保护写入携带 expected branch/head/tree 与唯一 command receipt；漂移 fail closed。
- ledger 逐条严格解析，commit/receipt 唯一，parent 只能指向前序 commit；checkout/head/tree、
  active branch snapshot、commit snapshot 与可见正文树互相验证。
- fork 从当前 head 克隆独立 branch state；switch 只物化目标既有 head，不制造跨分支历史。
- proposal 冻结 CAS，只能修改当前分支既有章节或 `plan/plot.md`；approve 原子提交，deny 不改正史，
  decision replay exactly-once。
- 中间章变更标记后续 unresolved；plot source/synced digest 决定 stale；两者只由 durable state 驱动。
- undo 追加 restore commit 并清除单层 undo，不删除旧 ledger。
- UI 只显示真实 active branch/status；错误通过 toast 可见；分支与历史动作在键盘压缩后仍可滚动到达。
