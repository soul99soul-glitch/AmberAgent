## 行为

- HM-1：已登记敏感工具的无效 JSON / 非对象输入统一变为不可回放标记。
  生成捕获、存储外置、执行器错误路径共用该边界；没有工具调用 ID 时也不返回原文。
  vault 不捕获无效输入，恢复时返回 `secret_input_unavailable`，存储回放判定为 `unavailable`。
- HM-2：只有 `ssh_host_trust` 的信任提交在双自动批准快捷分支前要求人工确认。
  仅探测指纹仍沿用既有权限规则；生成、导入、删除密钥和 profile 修改仍尊重高风险自动批准。
  解锁前台 verdict 创建进程内一次性确认，绑定调用 ID、输入、profile、完整路由摘要与指纹。
  审批 guard 将确认绑定到本次解析的参数对象，提交 pin 前再次核对实时目标；
  存储层在串行写入内部再核对路由，阻断排队中的跳板修改。
  持久化的 `approved` 标志无法重建确认，重启后需重新发起并确认。
