# 讨论一次回退最近 N 章

日期：2026-08-16  
状态：已锁定（用户选方案 1）

## 问题

最近几章写水时，作者只能在分支设定里连点「撤销上一次」。润色/同步也各占一个检查点，点起来费劲。讨论 agent 没有回退工具。

## 行为

讨论新增 `novel_revert_recent_chapters`。参数：`chapter_count`（最近连续 N 个未废弃工作章），可选 `reason`。

模型调用后出确认卡，列出将消失的章名。作者点「回退这几章」后：

- 按现有 `undoBranchHead` 语义连撤，直到这 N 章不在当前正文。
- 正文目录和剧情快照一起回到目标检查点（与单次撤销同一条领域路径）。
- 不新建检查点种类，不改 undo 时间线校验。
- 成功后不踢剧情重算：目标检查点已带当时的状态快照。

拒绝：代笔推进中、工作稿相对书头已分叉（先同步）、N 非法、章数不够、会越过分支 Fork/初始边界。

代笔 sidecar：若自动收录 ID 对应的章已不在工作稿，重算 `completedChapterCount`。不新开一批。

## 刻意不做

中间章删除、不经确认直接回退、只废弃不回状态、agent 连点「撤销上一次」按操作次数计。
