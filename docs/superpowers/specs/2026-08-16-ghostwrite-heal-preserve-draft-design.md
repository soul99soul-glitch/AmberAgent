# 代笔自愈：固化已确定正文

> Status: Approved for a thin try  
> Date: 2026-08-16  
> Depends on: `2026-08-09-ghostwrite-self-heal-loop-design.md`

## Outcome

验收不过时，**已写对的部分由宿主钉进下一次代笔输入**，只修正审稿指出的不确定处。质量门仍是验收；没过关的稿不得进正史。

## Locked

| 决策 | 选择 |
| --- | --- |
| 暂存 | 现有候选，不预收录、不推进分支 |
| 第一遍写 | 不动 |
| 自动 / 停人 | 代笔自动做 |
| 机制厚度 | **薄**：钉上一稿 + 改自愈提示；不做复审任务、不解析段落 |
| 质量栏 | 仍是验收；次数 / 熔断 / 过不了再整章 照旧 |

## Why

当前自动自愈写「重写完整一章、开篇换新」，且不带上一稿（只有人工润修带）。缺一句 must 会把已确定的 99% 扔掉，既压发挥，又降低通过率。

## Behavior

1. 无回执的首写：仍是「请按本章计划写完整一章正文。」
2. 自动自愈：把 `sourceCandidateID` 对应正文以 `【上一稿正文】` 灌入（有界，与润修同 12_000 字）。
3. 提示改为：已写好的视为已确定，只补审稿缺口；只有补了会破坏整章因果，才整章重来。禁止「开篇换新 / 从零重写」。
4. 仍产新候选、作废旧稿、再验；过了才收录。

## Non-goals

- 不预收录、不出审批卡、不加 must  
- 不做「能否局部改 + 段落范围」复审协议  
- 不改验收 schema、连续性、收录、同步
