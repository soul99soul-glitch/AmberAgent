## 关键约束(必须遵守)

1. **ArkTS 严格模式**:无 `any`/`unknown`(catch clause 除外)、无运行时 mutation(用 spread 不可变更新)、interface + factory function(不用 class mutation)
2. **测试方式**:`cd harmony/deepread && npm test`。注意 observable 测试有 setInterval 会 hang,要单独跑或用 AbortController 兜底清理。完整命令:
   ```bash
   cd harmony/deepread
   node --import tsx/esm --test --test-timeout=10000 src/test/*.test.ts
   # observable 单独:
   node --import tsx/esm --test --test-timeout=10000 src/test/observable.test.ts
   npx tsc --noEmit  # 必须干净
   ```
3. **import 路径用 `.ts` 后缀**:test 文件位于 `src/test/`,import 用 `'../main/ets/<dir>/<file>.ts'`(注意是 `../main/`,不是 `../src/main/`)
4. **Android 保真度优先**:设计文档里有详细的 Android 行为映射,移植时对照 Android 源码(`app/src/main/java/app/amber/feature/board/hotlist/deepread/` 和 `feature/board/impl/src/main/kotlin/app/amber/feature/board/hotlist/deepread/`)逐行验证。review 已经发现并修复了 4 个 fidelity bug,继续这个标准。
