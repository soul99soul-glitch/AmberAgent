# 二级页面尺寸调整

首轮以用户确认的 Session 首页尺寸为基准，缩小二级页面的视觉控件和留白。当时没有覆盖 `LocalDensity`、修改手机 DPI 或系统字体缩放，也没有改聊天和阅读正文的字体设置。后续用户单独指定的聊天字号调整见文末。

| 共用样式 | 调整前 | 调整后 |
| --- | --- | --- |
| 页面标题 | 19sp / 25sp 行高 | 17sp / 23sp 行高 |
| 常规 UI 文字 | 15sp / 22sp 行高 | 14sp / 20sp 行高 |
| 辅助 UI 文字 | 13sp / 18sp 行高 | 12sp / 17sp 行高 |
| 单行卡组最小高度 | 52dp | 48dp |
| 双行卡组最小高度 | 64dp | 56dp，内容更多时自然增高 |
| 图标瓦片 / 图标 | 32dp / 17dp | 28dp / 16dp |
| 常规页顶栏 | 56dp | 52dp |
| 默认开关视觉轨道 | 48 × 28dp | 44 × 26dp，点击区域保持 48dp |

Material 标题样式与上述层级对齐，Material 正文与标签小字样式保持原尺寸。提供商详情、添加提供商和模型编辑页中覆盖共用样式的大标题也已收紧。

子代理限制项在普通手机上为两行两列；卡内宽度不足 300dp 或系统字体缩放大于 1.2 时切回单列。角色说明保留完整换行，原有选项、值转换和持久化回调不变。模型议会卡内间距、独立标签和输入文字重新对齐，主持人、默认席位与运行参数的逻辑不变。
