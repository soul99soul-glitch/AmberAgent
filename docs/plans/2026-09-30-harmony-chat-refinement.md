# Chat 对话体验修正计划

保护当前回顾功能未提交改动，按用户六项反馈局部修正。以当前鸿蒙代码和 iOS 实际实现为依据，不扩展通用框架或全仓测试。

## Phase 1：顶部、气泡与添加入口

- 回顾胶囊随标题宽度变化，保留中心对齐和长标题上限。
- 模型面板从顶部滑入/收回；展开后同一服务商/模型入口可直接关闭。
- 用户气泡改为平滑连续圆角，保持现有文字布局和主题。
- 添加按钮保持严格圆形；地球入口接通明确的既有联网能力，若无实际能力则移除空入口。
- 完成后 subagent 检查调用链、尺寸、对齐及交互。

## Phase 2：统一思考框

- 对照 iOS，将思考头部与展开内容收口为同一个圆角框，取消重复标题和引用样式。
- 收起显示整数时长/正在思考；展开显示内容及低、中、高、最高等级。
- 保留思考内容设置、用户折叠选择及流式状态。
- 完成后 subagent 检查数据来源、状态与 UI。

## Phase 3：实时流式 Markdown 与交付

- 查证真实 chunk 到可见 Markdown 的链路，修复有证据的阻断或静态呈现问题。
- 本地延迟分块 provider 观察思考、Markdown 标题/列表/代码块的中间态与完成态；只对确切逻辑改动增加必要行为测试。
- 改动文件 lint、构建签名、浅深色模拟器目测，最后 subagent review。
- 思考等级分段控件缩至 28 vp；保留纵向回弹，取消 Chat 顶部滚动暗化及消息滚动条。
- Session 左右侧滑限定在 88 vp 操作区，删除只圆左侧、置顶只圆右侧。
- 更新安装真机并启动，单独记录真实 provider 和真机交互的验证边界。

## 进度

- Phase 1：实现与 subagent review 通过；同一模型入口关闭面板、垂直退出中间态、圆形添加按钮已在模拟器验证。
- Phase 2：实现与 subagent review 通过；思考档位、整数时长、审批入口与 think-tag 首次结束时间闭环已检查；浅深色思考布局已验证。
- Phase 3：真实慢 SSE、深色停止与 HTTP 503 错误隔离验证通过；代码和最终截图 review 通过。三点图标与气泡 26 vp 微调完成，最终包已安装真机并启动；QA 会话、设置和端口已清理还原。
