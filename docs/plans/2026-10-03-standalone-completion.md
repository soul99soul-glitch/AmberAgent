# 鸿蒙小说与深读独立产品完整化计划

目标：在现有两个独立应用上，逐项核对当前 iOS 实际生产能力，补齐鸿蒙产品缺口；按顺序完成全部 phase，每阶段独立 subagent 审查闭环、调用链与 UI，再精准修复后推进。

## 完成合同

- 每项生产能力有明确入口、实际调用、状态/数据保存、用户可见结果，以及必要的失败/取消处理；不以存在同名函数判定完成。
- 新能力接既有 repository/CAS、任务与模型运行路径；优先小模块，避免继续堆大页面；不删未理解/无关代码、不搬宿主密钥、不覆盖宿主数据。
- 每阶段只实现当前阶段；研究并行仅服务当前阶段，编辑分工有互斥 ownership。
- 阶段结束由未实施该改动的 subagent 审查；发现需代码证据或设备截图，定位到具体触发、调用和文件。修复后相关测试与必要 UI 回归通过才标记阶段完成。
- 功能测试、类型/lint、构建/签名、安装启动、真实 UI、云服务/系统后台分开记录。不把平台限制或缺少外部凭据冒充实现已验证，也不为此停下独立可推进的工作。
- 授权已覆盖实现、必要构建、现有模拟器独立包安装与审查；不发布、推送、创建 PR，不发送内容给外部接收人。

## 当前执行状态

P1–P8 全部完成并通过独立审查；最终回归、双包签名安装、冷启动及当前产物指纹核对完成。详细状态与逐阶段 review 存于 `docs/reviews/2026-10-03-standalone-completion/`。本轮按当前实际生产源码收敛任务，未沿用上一轮“可后置”作为忽略理由。API 12 为兼容基线；新系统 API 已查本地官方文档并按能力门禁接入。

## P4 实施边界

第四阶段沿既有 CAS 提案/工作区事务与 durable job 推进，分别负责专属工具及按段/范围提案、结构化事件与救援/修复、章节合同/后续计划与作者返修，以及可达 UI。数据模型、Creation、repository 的共享文件只按明确区域编辑，不整文件替换。UI 用独立页面/组件承接新增功能，不继续扩大 Workspace 主体。完成后另外分派未实施者检查真实调用链、陈旧证据拒绝和 UI；只修复已复现的问题。


## P5 实施与验收边界

P4 gate关闭后，分成四条互斥编辑职责推进：润色 durable job/runner/仓库润色区段；普通生成精确请求恢复与真实 Responses 传输；交换格式/收录克隆与归档资料；小说运行与交换的可达 UI。Creation、repository 的区段所有权写清，不整文件替换；系统通知/背景与导出入口沿现有 platform port，由 root 核官方 API 文档和集成。

验收必须穿过真实 runner/adapter/repository，而非只 mock 顶层：项目润色偏好只冻结一次且 alias/tag 与 branch override事实不丢；单章失败后后续章仍处理，失败集合显式重试且不重复收录成功章；普通重试用原请求/设置与部分稿；Responses 真正 GET 原 response ID + sequence，不能 POST新生成冒充恢复；公开/native文件新字段往返后可重读，真实保存/分享入口有效。无实际外部服务凭据的边界单独报告，不增加无依据重试或 fallback。

## P6 实施与验收边界

P5 独立审查关闭后再开始。逐项完成 DR-01～11，不重造已等效能力：发现与无链接热点采用当前源缓存/持久来源；模板归属捕获在文章与本次运行，阅读和 PDF 使用同一份捕获；搜索开关与首选服务接入实际 native 搜索客户端和取消生命周期；无工具模型沿原四阶段结构化生成，不只放宽校验；库监听真实 repository/run 事件并在离页释放；来源浏览与 TXT 系统文件出口沿已有 platform port；文档限额仅独立深读改为20MiB，新 HTML 模板直接提供可用 starter。

互斥责任为发现领域/发现设置 UI、深读模型运行与搜索、文章模板/库订阅与资料浏览导出 UI。共享 models/repository/pipeline/AppContainer 以明确区段所有权处理，保持已有运行恢复和旧文章保护。每条 UI 到调用器到持久结果/失败结果都要有实际测试，禁止增加无需求的自动重试、模型分类服务或权限旁路。实现完统一构建签名，再由未实施者独立 review，修复确证问题、核新包设备采集/四节输出/保存重读/导出闭环，关闭阶段后才进入P7。

## P7 实施与验收边界

两产品以当前P6安装包为起点，逐条核实际UI与caller。Novel Ghostwrite/Verdict潜在按值Builder首先做真实状态更新反例，只有确证不更新才精准改；不机械套用其它组件的修法。DeepRead Newsroom仅反映现RunStore真正阶段，随机阅读按iOS LuckyPick从当前有效发现条目选择，复用该条目的真实Article入口和缓存/生成行为，不引入虚假进度或新任务存储。主题、字体、键盘、长名字、弹层footer检查以截图和AX边界为准。所有变更统一lint/build/sign/device，再由未实施者独立复核关闭后进入P8。
