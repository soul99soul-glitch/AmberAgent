## 代码审查及修复闭环

原生杂志与宿主原生正文共享新章节排序及来源编号 helper。审查时发现混合旧稿中 `extendedReading` 被先显示为“扩展阅读”，随后又被并入“补充来源”，会重复出现同一链接。已向主 agent 提报；当前两个原生正文入口均已改为仅在统一 `sources` 为空时显示旧“扩展阅读”分组，新稿保留统一来源及去重后的补充资料。HTML 的对应旧字段兼容策略一致。

预览引用最初未产生滚动的 16/17 截图不计为通过。最终 base URL 修复后的 20→21 才是本报告采用的实点证据。
