# 重新学习指定会话的设计判断

参考：Synara 会话 `31bbdd72-9bf7-48bd-8da4-93d915f026b7`。本次再次分页读取全部 255 条消息，并重新查看紧凑首页、五种阅读样式、精读实稿和 Tab 切换逐帧图，核对对应 SwiftUI 与渲染源码。

## 应学习的具体取舍

1. **先判断内容用途，再选择视觉结构。** 消息 169–174 把“多源新闻综述”和“以原文为主的精读”区分开，批注附着于段落；设计跟随阅读任务。消息 202 也明确生成模板决定内容结构，不能用换皮肤代替。
2. **创意与状态直接相关。** 消息 75 的采访、整理、撰稿、付印映射真实生成阶段；标题铅字落位和完成盖印分别表达形成与完成。印章是这个时刻的反馈，不能据此推导所有品牌图标都应该变成字印。
3. **装饰有注意力成本。** 用户在消息 213 指出“AI 味儿”；消息 214、235、247 将彩条卡片与加号收敛为上标、细线和灰色脚注，使补充信息退到正文之后。
4. **空间优先服务内容。** 消息 131 将首屏报头收紧到约 150 pt，一屏热点由两张多增加到五张多，同时保留刊头、字体与编号特征。不能用大面积品牌展示取代可读内容。
5. **运动具有明确方向和稳定参照。** 消息 254 的 Tab 过渡沿切换方向横移约 30 pt，约 0.27 秒减速停住；纸面、标题、底栏稳定。消息 165–168 的闪烁修复证明，叠加更多动画可能损害连贯性。
6. **看真实效果，愿意推翻自己的方案。** 首屏空白、双重淡化、脚注装饰过重都经历实际反馈与修正。截图、测试和 reviewer 只提供不同类型的证据，不能相互替代。

## 对本轮图标的判断

- 字印版机械借用了会话的局部印章元素；大字加边框接近分类标签，不能据此证明具有品牌识别。
- 纸带版增强了材质与造型，但小说依赖笔尖说明用途，深读仍是通用书形；精细渲染不能自动解决独特性与记忆点。
- 当前两版均不应描述为已经获得用户审美认可。

## 后续图标工作的具体标准

- 先建立能分别表达创作与理解的独立符号轮廓，再决定材质、颜色和光照。
- 不依靠文字标签、笔尖小孔或纸纹等微小细节承担主要辨识。
- 两款通过共同的曲线、比例与负形组织建立家族感；反色只能作为其中一部分。
- 用桌面尺寸和系统掩膜检查形态，同时判断是否仍像通用写作/阅读素材。
- 将审美、构图、接入和安装分别评价；测试数量与 PASS 不作为审美完成条件。
