本轮实现、独立复审及本机验收完成；真机安装待 USB 设备恢复连接。

借鉴参考会话 31bbdd72-9bf7-48bd-8da4-93d915f026b7 的原则：纸面和标题层级稳定，创意来自出版流程，动效对应真实状态。首页收为衬线标题、刊头分隔线和单行真实统计，内容不再被大装饰占据。

## 已落地的交互

- 两首页长按刊头：开卷印记缩放落下、短暂停留并淡出，同时出现各自隐藏文案。统计与列表位置保持稳定。
- 小说正文页签：20vp 定向入场、240ms EaseOut，标题和页签保持原位。连续帧发现旧页淡出叠字，精确取消旧页的退出淡出，新包首个采样帧已无叠印。
- 小说收稿：正文持久化成功后在目录计数旁短暂盖章，完整新章保留原讨论归档选择流程。
- 深读编辑室：采访、整理、撰稿、付印的四步指示线跟随 scheduler 实际阶段；指示线滑动 260ms、阶段说明淡入 220ms。首次生成展示刊头与主题，重生成保留旧文与可取消操作。
- 深读付印：仅成功且整篇完整的持久化结果触发印记。旧缓存、失败、取消与状态回放不庆祝。离开返回、后台、主题重挂载不补播迟到印记。
