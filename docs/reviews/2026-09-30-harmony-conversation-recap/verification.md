# 鸿蒙对话回顾验证记录

日期：2026-09-30。基线：`d35e6864f`，分支：`harmony-preview`。三个 phase 均已完成，每个 phase 后均经过 subagent 只读 review；确认的问题已修复并复审。未提交、未推送。

## 实现结果

- 对话页上层动态区域打开回顾，下层独立切换模型和服务商。
- 至少 3 条用户消息可生成；概览最多 120 字，决策/里程碑/失败/产物节点最多 8 个，下一步最多 3 个。
- 使用标题任务模型，自动选择时回退对话模型；关闭工具与推理。独立配置的标题模型不依赖主聊天 runtime 可用。
- 回复完成后自动更新，包含工具批准后的完成路径；首次打开生成、手动刷新、失败重试、旧内容保留均接通。
- 节点引用稳定消息 ID，分支变化后不跳转到失效引用；可定位当前历史窗口外的原消息。下一步仅填入草稿。
- 独立 KV 缓存、同会话请求合并、在途完成后的后续更新、离页订阅清理、删除/恢复时缓存及在途结果失效均已实现。
