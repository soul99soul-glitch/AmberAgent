| Reachable flow | Entry control | Actual call and confirmation |
| --- | --- | --- |
| Paragraph revision | Project control → 正文操作与修改建议 → 按段改写 | Domain `novelChapterParagraphs` original UTF16 spans; full chapter metadata digest (`materialSuggestionChapterDigest`) + exact text + frozen CAS; `proposeManuscriptOperation` → durable review → `resolveWorkspaceProposal` |
| Recent N revert | Same page → 回退最近章节 | Explicit positive integer count → checkpoint proposal with complete before/after preview → existing approval |
| Multi chapter delete | Same page → 删除多章 | Actual chapter ID selection → visible title and before/after scope → existing approval |
| Draft/confirmed chapter contract | Project control → 本章计划与走向 | Six contract fields, draft/confirm/clear and model draft suggestion; same CAS transaction, author confirmation before persistence |
| Upcoming arc | Same page → 保存后续走向 | At most 8 lines, each at most 160 characters; reject excess while preserving input |
| Structured state | Project control → 剧情状态与人物经历 | Same snapshot returns project/CAS; explicit latest chapter sync and full rescue; durable progress subscription, error, cancellation and retry |
| Character evidence and identity | Same page | Name/aliases/summary/verbatim source quote; source and branch checked before Reader; author chooses create/ignore/merge with frozen CAS |
| Audit repair | Plot pane → audit issue → 生成修复建议 / 全部生成修复建议 | Single/all issues stage one durable review; actual cancel and hide/disappear cancel await model termination, without a half proposal; route focuses resulting proposal before composer; author approves exact change |
| Chapter directional revision/regeneration | Reader → 按要求修订本章 / 整章重新生成 | Scope and author brief sheet; frozen target/CAS; existing candidate collection/approval retains source until accepted |
| Paused/failed ghostwrite brief | Project control → 按要求返修代笔 | Visible branch and chapter, frozen job/CAS/candidate digest; next-draft-only brief, existing writing driver |
| State reasoning | State page → 状态整理使用推理 | Off by default, persisted author toggle; actual domain structured extraction reads it |
