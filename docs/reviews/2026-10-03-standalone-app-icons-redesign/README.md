# Amber 独立应用图标重设计 · 2026-10-03

## 参考与设计原则

已通过 Synara read_thread 分页阅读会话 `31bbdd72-9bf7-48bd-8da4-93d915f026b7` 的 0–254 条消息（共 255 条）。重要依据：

- 消息 75：编辑部杂志纸感、报纸刊头、朱红编号、铅字托盘与付印印章。
- 消息 142：朱砂 / 黛蓝 / 松绿 / 藤紫 / 墨黑的受控色谱，以及杂志、书卷、报纸等阅读风格。
- 后续关于脚注与页面过渡的反馈：减少装饰，保持纸面稳定，优先内容秩序。
- 实际查看 iOS `DeepReadApp/build/design-2026-10-03/discovery-masthead-seal.png` 与 `newsroom-typetray.png`，以及当前 iOS AppIcon。

可借鉴的原则：

1. 视觉围绕出版和阅读建立主题，图形、字形、材质和交互共同服务这一主题。
2. 暖纸与朱砂以少量、高对比的组合形成品牌；色彩数量少，主次清楚。
3. 字形本身承担识别，精确控制笔画、比例和留白。
4. 两个独立产品保留共同的视觉语法，通过主字和正负色关系区分。
5. 在真实桌面尺寸检验效果。资源接入正确、review 通过不能证明审美获认可。

## 最终方案：出版字印

- Amber 小说：朱砂底、纸白「文」。文表示写作与成篇。
- Amber 深读：暖纸底、朱砂「读」。读直接对应阅读。
- 共用 688 px 印框、22 px 框线与 552 px 字形边界，画布 1024 px；文字中心上移 4 px 做视觉调整。
- 朱砂 `#C8402F`、纸白 `#FBF7F1` 来自参考设计。
- Noto Serif SC 850 字重转换为路径，精整宋体印记，不模拟篆刻或做旧。
- 移除上一版纸张堆叠、星光、轨道等装饰；保持单一主字。
- 纯不透明正方形 PNG；桌面圆角交给系统；SVG 为可编辑源。

## 独立审查

Subagent 实际查看参考图、新图与 128 / 64 / 48 px 缩略图：

- 家族关系和参考方向明确；48 px 能辨字，框与字间未见拥挤或偏位。
- 具体限制：「读」的笔画和墨量大于「文」，反色缓和这一差异，不宜机械扩大读字。
- AppScope 与 entry PNG、EntryAbility icon / startWindowIcon 均连接产品专用资源；避免原通用 app_icon 限定目录覆盖。
- 桌面复查：subagent 已查看模拟器掩膜后效果和两款冷启动图；框线、裁切、边距未见明显问题。读字笔画更密，但反色后无需扩大或压缩字形。
- 审美结论由用户判断，审查不以 PASS 代替审美认可。
