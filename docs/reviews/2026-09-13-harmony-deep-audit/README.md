# HarmonyOS Agent 全范围、证据驱动 Bug 审查

**日期：2026-09-13｜对象：当前工作树｜审查，不修复**

## 执行摘要

本轮完成覆盖地图、A–H专题及深读/搜索/议会/小说等扩展域的关键实现审查、8条跨模块旅程追踪和独立反证复核。**最终确认26项当前代码缺陷（P1 8项、P2 14项、P3 4项），另列2项已证实的P1级潜伏WebMount安全缺陷；未确认P0。** 潜伏项的真实工具逻辑已复现，但当前挂载故障与构建失败遮蔽设备端利用，不能表述为已发生隐私泄露。

最需要优先处理的风险：

1. **当前工作树构建失败。** Crypto/OAuth未提交改动使用了不存在的API及不合ArkTS约束的类型，CompileArkTS无法通过。
2. **数据保护闭环仍有缺口。** 备份扁平化丢消息分支；结构异常的有效归档可部分覆盖后失败；RDB故障静默进入临时内存，恢复前退出丢降级期改动；一次读IO错误后写入可覆盖记忆/附件追踪原数据。
3. **模型和工具错误能改变实际行为。** Provider错误正文含“abort”会被当取消并回写旧会话，抹去已保存的新user；200非SSE静默无回复；缺工具ID的非合规网关可触发审批/结果身份错配。
4. **自动化状态机不完整。** Cron有重叠执行、无当前运行取消能力、远期delay被截断提前执行，且实际仅单轮文本生成没有工具；子代理待审批后不可恢复/取消。
5. **授权边界与自然语言续跑混淆。** “继续写首诗”可批准全部pending工具；WebMount还存在脚本参数注入和URL白名单解析缺陷，必须和挂载修复一起处置。

## 最重要的反证与收窄

- 深读正常规划会从全局池补证据；只有规划失败的fallback后段可能空。原P1降R24/P3。
- 正常Claude有初始tool ID，OpenAI后到ID会merge；工具空ID问题限定非合规网关，不泛化。
- 子代理approval_required确实不能cancel，但不占running并发额度。
- RDB恢复成功会回灌内存；风险是恢复前退出丢新增/编辑，不是删除旧数据库。
- 普通密文破坏会被sha/GCM拒绝；恢复结构缺陷不是加密认证绕过。
- DeepRead通知publish与cancel都未等待平台操作；确认竞态，不能说每次完成必然消失。
- run-trust在生产无赋值，不能拿它证明当前越权；MCP真实start自清理也否定了抽象坏transport的泄漏推断。
- 孤儿旧页存在替代活入口，不单独计功能缺失；主题响应/大字体/键盘必须等待设备证据。
