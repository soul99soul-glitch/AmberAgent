## 问题与结果

- 正文收录后自动询问归档讨论，打断创作。移除自动弹窗，收录直接返回正文目录；创作模式菜单中的手动归档入口保留。
- 资料建议的原提示词示例将 kind 写成 world|character|relationship|outline|requirement|other，模型照抄会被真实解析器拒绝。示例改为有效单值，允许类别单独说明。只在完整返回但结构错误时纠正一次，带原章节、资料及上次输出，继续使用原验证器；共享原 90 秒期限，不重试网络、超时或供应商错误。
- 讨论归档原来直接 JSON.parse，完整合法 JSON 带 Markdown 代码围栏也会失败。仅拆除完整围栏，保留原结构校验。资料分析原本已支持围栏，不重复添加解析分支。
- 资料分析失败仍保留正文和剧情同步点；界面显示可理解的格式提示和逐章重试入口，不直接展示 JSON 技术错误。手动重新分析时清除旧收录提示并递增令牌，防止旧异步反馈重新出现。
